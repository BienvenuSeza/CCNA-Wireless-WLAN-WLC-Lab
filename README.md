# CCNA Wireless, WLAN & WLC Lab

## Project Overview

This project documents a practical Cisco Packet Tracer lab focused on wireless networking, Wireless LAN Controllers (WLC), and WLAN configuration.

The objective is to develop hands-on networking skills aligned with the Cisco CCNA 200-301 certification.

## Network Topology

The lab includes the following devices:

- Cisco 3504 Wireless LAN Controller (WLC)
- Cisco Catalyst 2960 switch
- Lightweight Access Points (LAP)
- Server
- Wired client
- Wireless client (smartphone)

## Technologies and Concepts

- Wireless LAN (WLAN)
- Service Set Identifier (SSID)
- Wireless LAN Controller (WLC)
- Lightweight Access Point (LAP)
- VLAN configuration
- IP addressing and DHCP
- Wireless client connectivity
- Network troubleshooting

## Lab Objectives

1. Understand the wireless network topology.
2. Configure switch ports and VLANs.
3. Configure WLC management and interfaces.
4. Create and configure a wireless network (SSID).
5. Configure wireless security.
6. Join lightweight access points to the WLC.
7. Connect wireless clients.
8. Test and troubleshoot network connectivity.
